Every maker knows this moment. The circuit finally works on the breadboard, and now it has to become something real. Cheap perfboard has pads that lift after one rework. A custom PCB for a one-off build means days of design and two weeks of waiting. And soldering a dev board onto plain perfboard means guessing which hole is GPIO 4.

So I built DIY Universal Boards: a family of 24 open-source PCBs, all on one 2.54 mm grid, with plated holes, clear labels and real mounting holes. The Gerber files are free. Download the boards you need and order them from any PCB maker.

Download all Gerbers on GitHub

Why I made this

In 2019 I shared a simple 100 × 50 mm DIY universal board. It was a plain board, but I kept reaching for it. I also kept wishing it came in other sizes, with power rails, as a breadboard copy, and in versions that fit my Raspberry Pi Pico, ESP32 and Arduino Nano. So I redrew it from scratch and turned it into a complete family with one design system: the same holes, the same pads, the same labels and the same mounting holes on every board.

Highlights

Breadboard PCB

Copy your breadboard hole for hole. Rows a–e and f–j are linked on the bottom like a real breadboard, with a centre channel for DIP chips and four + / − rails. Put every part exactly where it was on the breadboard and solder.

Raspberry Pi Pico proto board

Pico socket rows with every pin name printed (GP0–GP28, VSYS, VBUS, RUN…), and two extra linked holes on every pin so you never squeeze two wires into one hole.

ESP32 DevKit 38-pin proto board

The top header has two linked rows, so both the 0.9″ and the 1.0″ wide ESP32 DevKit boards fit. Great for ESPHome and home-automation builds.

Arduino Uno proto shield

The real Uno R3 outline, headers (including the famous 160 mil D7–D8 gap) and mounting holes. There's no copper over the Uno's USB connector, so it can't short.

Raspberry Pi HAT-size proto board

HAT size and holes, the 40-pin header in the standard place, and a linked hole for every GPIO pin with its BCM name.

SMD adapter board

Use modern SMD chips in a through-hole build: SOIC-16, SOIC-8, SOT-23, 0805 and 1206 footprints, each pin wired to a 2.54 mm hole.

PCB ruler 15 cm

A ruler and a bench reference card in one: copper mm and inch scales on both sides, drill and AWG wire gauges, trace widths with current ratings and 21 labelled SMD footprints. Order it with ENIG for shiny gold scales.

Common specs

  • 2.54 mm (0.1″) grid
  • 1.0 mm plated holes, 1.8 mm pads on both sides
  • Plated M3 mounting holes 3.5 mm from each corner (shields and the HAT use their real mounting hole positions)
  • Linked holes use 0.8 mm copper on the bottom, so you can cut them with a knife
  • Every board passes the design rule check with zero errors

How to order

  1. Open the GitHub repository and download the Gerber zip for the board you want (in the gerber folder).
  2. Upload the zip to your favourite PCB maker.
  3. Choose 2 layers, FR-4, 1.6 mm, HASL, any colour. No special options are needed. For the rulers, pick ENIG (gold).
  4. Solder, build, and share what you made!

Tips for the carrier boards

  • Use female headers so you can take the module out again.
  • Check the printed pin names match your module before soldering. Clone boards sometimes change the pin order.
  • GND and power pins are not joined to each other, so wire the ones you use.

LED Chaser PCB Ruler

A PCB ruler with a working circuit: a TLC555 timer and a 74HC4017 counter run a rainbow light along the scale. It runs from a CR2032, every part is on top so the back stays flat, and it comes with a full BOM and pick-and-place file for assembly. It makes a great SMD soldering practice kit.
