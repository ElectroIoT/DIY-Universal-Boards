## Description (paste into the project description)

### Why I made this
In 2019 I shared a simple 100 x 50 mm DIY universal board. I kept using it, and I kept wishing it came in more sizes and in versions made for the boards I use every day. So I redrew it and built a whole family of 24 open-source boards: proto boards on one 2.54 mm grid, dev-board carriers, shields and PCB rulers, all with the same quality and clear labels. This board is one of them.

### What's on the board
- 35 x 13 dot grid
- Two + / - rail pairs, one on each long edge, linked on the bottom
- Top and bottom rail pairs are separate, so you can run two voltages (e.g. 5 V and 3.3 V)
- 4 plated M3 mounting holes
- 2.54 mm (0.1") grid: DIP chips, pin headers and breadboard parts fit directly
- 1.0 mm plated-through holes with 1.8 mm pads on both sides: pads don't lift when you rework
- Every board passes the design rule check with zero errors

- HASL (lead-free is better if you give boards away)

### Tips
- Join the top and bottom rails with a wire if you need only one supply
