# Arduino Uno Proto Shield

## Title
Arduino Uno Proto Shield

## Short description (summary box)
Uno R3 shield shape with all headers, an extra hole per pin, labels and a dot grid.

## Tags
arduino uno, shield, proto shield

## Description (paste into the project description)

### Why I made this
In 2019 I shared a simple 100 x 50 mm DIY universal board. I kept using it, and I kept wishing it came in more sizes and in versions made for the boards I use every day. So I redrew it and built a whole family of 26 open-source boards: proto boards on one 2.54 mm grid, dev-board carriers, shields and PCB rulers, all with the same quality and clear labels. This board is one of them.

### What's on the board
- Uno R3 outline and the 4 Uno mounting holes
- R3 headers with the 160 mil D7-D8 gap: power, A0-A5, D0-D13, AREF, SDA, SCL
- 1 extra linked hole per header pin, all pins labelled
- No copper over the Uno's USB connector, so it can't short
- Dot grid in the middle
- 2.54 mm (0.1") grid: DIP chips, pin headers and breadboard parts fit directly
- 1.0 mm plated-through holes with 1.8 mm pads on both sides: pads don't lift when you rework
- Every board passes the design rule check with zero errors
